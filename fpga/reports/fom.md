# Figure of Merit worksheet

Generated by `vivado -mode batch -source fpga/fom.tcl`. Do not edit by hand.

    FoM = Throughput / (Power x (LUTs + 50 x DSPs + 100 x BRAMs))

Throughput is **1.0 output pixel/cycle** by construction under continuous
`px_valid` (docs/02_architecture.md s8). It is not measured from a
wall-clock rate: the regression proves exactly (W-N+1)^2 qualified outputs
per frame with no stall path anywhere in the datapath.

## Notes on reading these numbers

* Utilization comes from **out-of-context** synthesis, so it is the core
  alone with no I/O buffers -- the honest number for a FoM that is about
  the accelerator, not about a pin-out.
* Fmax is an estimate derived from achieved slack. The figure quoted in the
  report must come from a clean run AT that constraint (docs/06 s2);
  never report a frequency with WNS < 0.
* Because the FoM numerator is throughput **per cycle**, a higher Fmax buys
  nothing in FoM -- it only improves absolute Mpx/s. That is the whole
  reason the LUT variant is expected to win: 9 DSPs would add 450 to the
  cost term for no numerator gain (docs/06 s6).
